# cara-ecommerce
A responsive E-commerce store project showcasing my skills in front-end development, featuring interactive cart management, dynamic product display, and local storage integration for a seamless user experience
##Features 
- Dynamic Product Display:
                           Browse through a curated list of products with interactive views.
- Interactive Cart Management:
                           Easily add or remove items to the shopping cart with real-time updates.
- Local Storage Integration:
                           Your Cart items are saved locally, ensuring a seamless experience even after reloding the page.
- Responsive Design:
                           Fully optimtzed for different screen sizes and devices
  ## Technologies Used
- HTML5
- CSS3
- javaScript(vanilla)
